# Free sprites

All options below are CC0 (public domain, commercial use fine, credit optional but nice).

## Furniture and building

- **Kenney Furniture Kit**: 3D furniture and building materials, with 2D isometric renders from 4 angles. Best fit for desks, chairs, computers, plants. https://opengameart.org/content/furniture-kit
- **Kenney Isometric Miniature series** (Library, Bases, Dungeon): 256x512 isometric tiles, rendered at 30° x 45°. Library has shelves and furniture usable as office props. https://opengameart.org/content/isometric-miniature-library
- **Kenney Isometric Assets bundle** (itch.io, paid, with free preview): hundreds of iso tiles plus Tiled templates. Note it uses a different angle (35.264° x 40°), so do not mix it with the Miniature series. https://kenney.itch.io/kenney-isometric-assets

## Characters (the gap)

There is no great free set of isometric office workers. Options:

1. **Procedural placeholder people** (circle head, colored body per role). Readable, zero effort, fits the humor. Start here.
2. **Puny Characters**: CC0, 8 directions, idle and walk animations. Pixel fantasy style, clashes with Kenney's clean renders. https://opengameart.org/content/puny-characters
3. **Render Kenney's 3D Mini Characters to iso sprite sheets** with a Blender script (the agent can write it). Consistent with the furniture style, more work. Best long-term option.

## Rules

- Keep the angle consistent: pick one family per category
- Record every pack in `CREDITS.md`
- Never use assets from Theme Hospital or other commercial games
