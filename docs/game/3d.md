# The 3D look

Every screenshot in these docs, taken again with the 3D look (phase 14, see [the plan](../plan/phase-14-3d-graphics.md)). The game still starts in 2D; open it with `?render=3d` to play in 3D. The other pages show the 2D pictures; the 3D ones are all here, with the same names in [`images-3d/`](images-3d/).

To take them again, start `npm run dev` (and `npm run server` for the online lobby picture, but stop it before the rest: the online shot leaves the tab rejoining that room), then:

```bash
npm run screenshots -- --render=3d --out=docs/game/images-3d
```
